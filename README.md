# RankWit Meet

La pagina per prenotare una call con il team di RankWit AI: una call con il team assegnata a turno, le call per tema e una pagina per ogni persona. Gli orari arrivano dai calendari cal.com del team e ogni call si fa su Google Meet.

Sito statico, senza build: `index.html`, `app.js`, `app.css`, `config.js` (persone, call, fiere) e `orchestrator.js` (turni della call con il team). La copia di lavoro è in `Website/book (N)`; questa cartella è quella pubblicata su GitHub Pages.
